# 메이커즈 템플릿

5주 동안 Claude와 대화하며 **내 아이디어를 구체화하고, MVP를 만들고, 고객을 만나 보는** 작업 공간이에요.
끝나고 나면 이 레포가 **AI와 함께 계속 만들고 운영하는 나만의 시스템**이 돼요.
개발을 몰라도 괜찮아요. 대화만 하면 Claude가 문서를 채워 줘요.

> 처음이라면 **[메이커즈 템플릿 사용법](https://claude.ai/artifact/N66tCKUhNG5XqknJfeJ8tq)** 을 먼저 읽어 주세요. Git이 뭔지부터 셋업, 주차별 과제, 막혔을 때까지 다 있어요.

---

## 처음 한 번만: 셋업 (1주차 모임에서 같이 해요)

1. **GitHub 가입** → 이 페이지 위의 초록색 **Use this template** → **Create a new repository**
   - 이름: `makers-내이름` / 공개 범위: **Private**
2. **GitHub Desktop** 설치 → 로그인 → 방금 만든 레포를 **Clone** (내 컴퓨터로 받기)
3. **Claude 데스크톱 앱**에서 Cowork를 열고, 받은 폴더를 연결
4. Claude에게 **"1주차 메이커즈 시작하자"**라고 말하고, 사전과제 폼에 쓴 내 답을 붙여넣기

> Claude가 파일을 지워도 되는지 물으면 **허용**해 주세요. 저장(커밋)할 때 필요해요.

## 이렇게 말하면 돼요

| 이렇게 말하면 | Claude가 하는 일 |
| --- | --- |
| **"1주차 메이커즈 시작하자"** | 그 주차 인터뷰를 한 번에 한 질문씩 진행 (2주차, 3주차…도 같은 방식) |
| **"메이커즈 시작하자"** | 지금 어디까지 했는지 보고 다음 주차를 알려 줌 |
| **"MVP 만들자"** | 내 아이템에 맞는 가장 작은 버전을 같이 만들기 |
| **"요약 만들어줘"** | 이번 주 회고 + 슬랙에 붙일 주간 요약 |
| **"포트폴리오 만들어줘"** | 지금까지 기록으로 포트폴리오 |
| **"오늘 끝"** | 오늘 바뀐 것 정리하고 저장 |
| **"이번 주 뭐 하지?"** | 메이커즈가 끝난 뒤, 액션플랜 보고 이번 주 할 일 정하기 |

이것도 돼요: **"SSOT 보고 인스타 소개글 써줘"**, **"SSOT 보고 랜딩 페이지 문구 만들어줘"**

## 한 주의 흐름

| 언제 | 할 일 |
| --- | --- |
| 목 | 모임: 공유하고 피드백 받기 |
| 금~일 | "N주차 메이커즈 시작하자" → 인터뷰 1~2시간 (나눠서 해도 돼요) |
| 월~화 | 직접 실행하기 (3~4시간) |
| 수 | "요약 만들어줘" → 주간 요약 올리기 |

저장한 뒤에는 GitHub Desktop에서 **Push origin** 버튼을 한 번 눌러 주세요. 온라인에도 저장돼요.

---

## 5주의 흐름

| 모임 | 그 다음 한 주에 하는 일 |
| --- | --- |
| 1회 **OT** | 아이디어 구체화: 왜, 누구, 어떤 문제, 어떻게, 가설 |
| 2회 **IDEA** | 가장 작은 버전(MVP) 만들기, 내 아이템 형태에 맞게 |
| 3회 **MVP** | 고객 만나기: 보여 주고, 써 보게 하고, 듣기 |
| 4회 **CUSTOMER** | 다듬기 + 포트폴리오 + 다음 4주 액션플랜 |
| 5회 **SHOWCASE** | 발표하고 Keep going 시작 |
| 이후 **KEEP GOING** | 액션플랜대로 계속 (모임은 격주·월 1회) |

> 주차는 **1주차부터 차례대로** 진행해요. 앞 주차를 끝내지 않고 다음 주차를 시작하면, Claude가 빠진 것을 알려 주고 앞 주차부터 이어서 해요.
> 주차를 끝냈다는 기준: 그 주차의 필수 칸을 채우고, "요약 만들어줘"로 주간 요약을 확정하기.

## 내가 볼 파일

- **`SSOT.md`** 나의 기준서. 나, 아이템, 실험과 결정, 액션플랜이 다 여기 있어요.
- **`weeks/`** 주차별 한 장. 이번 주 목표와 기록.
- **`mvp/`** 내가 만든 MVP.
- **`portfolio/`** 발표에 쓰는 포트폴리오.

나머지(`records/`, `_system/`, `CLAUDE.md`)는 Claude가 관리해요. 안 봐도 돼요.
