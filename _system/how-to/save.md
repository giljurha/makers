# 저장 진행법 (git)

크루에게는 "저장"이라고만 말한다. git, 커밋 같은 말은 쓰지 않는다.

## 저장하기
1. "이대로 저장할까요?" → 확인받은 것만.
2. 저장 메시지는 한국어 한 줄: 무엇이 왜 바뀌었는지. 예: `1주차: 아이디어를 '동네 그림 모임'으로 정함`
3. 저장 뒤 안내: "GitHub Desktop에서 **Push origin** 버튼을 눌러 주세요. 온라인에도 저장돼요."

## 막힐 때
- **처음 저장할 때 이름이 없다고 나오면:** 크루 이름과 GitHub 이메일을 묻고 이 레포에만 설정한다 (`git config user.name`, `git config user.email`).
- **파일을 지울 수 없다는 오류 (lock 파일 등):** 이 폴더에서 파일 삭제 권한을 요청한다. 이유는 "저장할 때 임시 파일을 지워야 해요".
- **이 폴더가 git 레포가 아니라고 나오면:** README의 셋업(GitHub Desktop으로 Clone)을 다시 안내한다. ZIP으로 받은 경우다.
- 그래도 안 되면 저장은 건너뛰고, 다음 모임에서 운영자에게 물어보라고 한다. 파일은 이미 고쳐져 있으니 내용은 사라지지 않는다.
