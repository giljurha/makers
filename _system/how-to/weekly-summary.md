# 주간 요약 진행법 ("요약 만들어줘")

## 1. 회고 (질문 4개, 한 번에 하나씩)
- 이번 주에 정한 것은?
- 막혔던 것은?
- 가장 도움이 된 질문은?
- 다음 주에 바꿀 것은?
→ `weeks/week-N.md` 회고 칸

## 2. 주간 요약 만들기
`weeks/week-N.md`의 실행 기록, 회고, SSOT를 보고 아래 형식으로 만든다. 크루가 쓴 말을 최대한 그대로 쓴다.

```
[메이커즈 N주차] 이름 · 아이템 한 줄
✅ 이번 주 실행: (1~2줄)
📎 실행 증거: (링크 또는 "사진 첨부")
💡 발견한 점: (1~2줄)
➡️ 다음 행동: (1줄)
```

## 3. 확인과 마무리
- 요약을 보여 주고 "이대로 올릴까요?" → 고칠 점 반영
- 확정본을 `weeks/week-N.md` 주간 요약 칸에 저장
- SSOT "진행 요약" 표의 N주차 줄을 채운다
- 슬랙에 붙여넣으라고 안내 (증거 사진은 직접 첨부)
- `python3 _system/check.py status`로 이번 주차가 "완료"인지 확인한다. 빠진 칸이 있으면 알려 주고 채운 뒤 끝낸다.
- 저장 (`save.md`)
