# MVP 진행법 ("MVP 만들자")

MVP는 **가설 하나를 확인하려고 만드는 가장 작은 버전**이다. 완성품이 아니다.
크루 대부분은 개발자가 아니다. 만드는 건 Claude가 하고, 크루는 고르고 확인한다.

## 트랙 메뉴
| 트랙 | MVP 메뉴 (하나 고르기) | Claude가 만드는 것 | 공개 방법 |
| --- | --- | --- | --- |
| 웹·앱 | 랜딩 페이지 / 한 기능짜리 웹앱 | `mvp/index.html` (파일 하나) | Netlify Drop 링크 (아래) |
| SNS·콘텐츠 | 채널 소개 + 게시물 3~5개 | `mvp/posts.md` (문구, 이미지 아이디어, 해시태그) | 크루가 직접 업로드 |
| 모임·커뮤니티 | 모임 공지 + 신청 폼 문항 | `mvp/announcement.md` | 오픈채팅, 커뮤니티, 구글폼 |
| 상품 | 상품 소개 페이지 / 사전 주문 안내 | `mvp/index.html` 또는 `mvp/product.md` | Netlify Drop 링크, SNS, 지인 |
| 서비스 (사람이 직접) | 서비스 소개 + 신청 방법 | `mvp/service.md` | 1~3명에게 직접 제안 |

## 순서
1. SSOT ②③을 읽고 "이 MVP로 확인할 가설"을 한 줄로 확인받는다.
2. 메뉴에서 하나 고르게 한다.
3. 꼭 들어갈 것 3가지를 고르게 한다. 나머지는 범위 밖.
4. 초안을 만든다. 문구는 SSOT ① 말투와 ② 한 줄 설명에 맞춘다. 없는 사실(가격, 후기, 숫자)은 지어내지 않고 빈칸으로 둔다.
5. 보여 주고 고칠 점을 한 번에 하나씩 묻는다.
6. 공개 방법을 안내하고, 링크를 SSOT ② MVP 칸에 적는다.
7. 저장 (`save.md`).

## 링크로 공개하기 (Netlify Drop)
크루에게 이렇게 안내한다. 레포는 Private 그대로 둔다.
1. 브라우저에서 **app.netlify.com/drop** 열기
2. `mvp` 폴더를 통째로 끌어다 놓기 → 링크가 바로 생겨요
3. 무료로 가입하면 링크가 계속 유지돼요 (가입 안 하면 잠깐만 열려요)
4. 고친 뒤 다시 올리려면: 사이트 화면의 **Deploys**에 폴더를 다시 끌어다 놓기
생긴 링크는 SSOT ② MVP 칸에 적는다.

## 주의
- 2주차 안에 만들 수 있는 크기로. 막히면 더 작게 자른다.
- 결제, 로그인, 개인정보 수집이 필요한 기능은 만들지 않는다. 신청은 구글폼 같은 기존 도구를 쓴다.
