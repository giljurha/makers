# 3주차 질문 은행 · CUSTOMER

**목표:** 고객이 어디 있는지 찾고, 실제 사람에게 MVP를 보여 주고 반응을 모은다.
**시작 말:** "3주차 메이커즈 시작하자"
**끝 조건:** 고객 2~3명 이상의 반응이 실행 기록에 있고, ③ 가설에 결과가 있다. → `python3 _system/check.py status`에서 3주차 "완료"

## A. MVP 공유 돌아보기
- 모임에서 MVP를 보여 줬을 때 가장 의외였던 반응은?
- 고칠 것 중 고객을 만나기 전에 꼭 고쳐야 하는 것 하나만 고르면?

## B. 고객 찾기
- 내 고객은 평소 어디에 있나요? (예: 오픈채팅, 커뮤니티, 인스타 해시태그, 동네 모임, 학교·회사, 지인의 지인)
- 이번 주에 만날 2~3명은? (이름 대신 "A님" 같은 별칭)
- 처음 연락할 메시지 → Claude가 초안 2개, 크루가 고르고 고친다.

## C. 무엇을 물을까 (트랙에 맞게)
- 질문지 5개 이내. 원칙: 내 아이디어를 설명하기 전에 그 사람의 경험부터 묻는다. ("최근에 ○○ 때문에 불편했던 적이 있나요?")
- 웹·앱/상품/서비스: 직접 써 보게 하고 "어디서 멈췄는지" 본다.
- SNS·콘텐츠: 반응 숫자 + 댓글·DM으로 이유를 묻는다.
- 모임: 한 번 열고 끝나고 3가지 묻는다 (좋았던 것, 아쉬운 것, 또 올지).

## D. 기록
- 만난 뒤: 별칭, 들은 말(원문), 배운 것 → 실행 기록. 이름·연락처는 쓰지 않는다.
- ③ 가설 표의 결과와 배운 것을 채운다.
