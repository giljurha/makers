# 운영자 안내 (Kody)

크루는 이 파일을 안 봐도 돼요.

## 템플릿 배포
1. 이 폴더를 GitHub 레포로 올린다. 2기부터: https://github.com/KodywiththeK/makers-template
2. 레포 **Settings → General → Template repository** 체크.
3. 레포는 Public으로 둔다 (크루가 템플릿으로 복제하려면 볼 수 있어야 함). 크루 레포는 각자 Private.
4. 기수마다 바뀌는 건 이 파일의 일정뿐. 템플릿 본문에는 날짜를 넣지 않는다.

## 사전과제
템플릿과 별개로, 첫 모임 전에 구글폼 링크로 직접 보낸다. 질문지 문안은 운영 폴더의 `program/pre-survey.md`에 있다.
폼 설정에서 **응답 사본 보내기**를 켜 두면 크루가 첫 모임에서 자기 답을 템플릿에 붙여넣기 쉽다.

## 주차 순서 하네스
- 크루는 "N주차 메이커즈 시작하자"로 시작한다. Claude는 먼저 `python3 _system/check.py N`을 실행해 앞 주차가 끝났는지 본다.
- 앞 주차가 덜 끝났으면 빠진 것을 알려 주고 그 주차부터 진행한다.
- 완료 기준은 `_system/check.py`의 주차별 필수 칸 + 주간 요약 확정. 기준을 바꾸려면 이 파일의 `missing()`만 고치면 된다.
- Claude Code에서 열면 `.claude/settings.json`의 훅이 같은 검사를 자동으로 붙인다. Cowork에서는 CLAUDE.md 규칙으로 한다.
